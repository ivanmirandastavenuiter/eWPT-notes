## WEB SERVICE SECURITY TESTING

### 1. Web service security testing

#### 📌 1.1. Introduction

**Basic concepts**

- Definition → Evaluating security of web services to identify vulnerabilities, weaknesses and potential threats that could compromise confidentiality, integrity or availability of the service or its data.

**Process**

- Information gathering and analysis
    1. Identify SOAP web services that need to be tested
    2. Identify the WSDL file
    3. Gather information about web service endpoints, operations and data exchanged
    4. Understand the security requirements, authentication methods and authorization mechanisms in place  
- Threat modeling
    1. Identify potential security threats and vulnerabilities specific to SOAP web services
    2. Threats to consider: unauthorized access, data injection, XML-based attacks

**Next steps**

Continue with the following, only if found

- Authorization and authentication testing
- Input validation

#### 📌 1.2. WSDL disclosure

It is the step that follows the identification of the SOAP web service and the endpoints

- Accessing the WSDL file is the next step
    1. Full list of operations and correct syntax to use
    2. Inputs and outputs
